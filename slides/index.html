🔄 Protocolo HTTP - Métodos e Status

Métodos HTTP (Verbos)

GET → Buscar dados (Ler)

POST → Criar novo recurso

PUT → Atualizar recurso existente

DELETE → Remover recurso

Códigos de Status

200 OK - Sucesso

201 Created - Recurso criado

400 Bad Request - Erro do cliente

401 Unauthorized - Não autenticado

404 Not Found - Não encontrado

500 Internal Server Error

🌐 O que é uma API?

API (Application Programming Interface) é um contrato que permite dois softwares conversarem entre si.

Analogia: O Garçom

🧑 Você (Cliente) → 📋 Cardápio (Docs) → 🤵 Garçom (API) → 🍳 Cozinha (Servidor)

Você não vai na cozinha. O garçom (API) leva o pedido e traz a resposta.

Por que usar APIs?

  • Não reinventar a roda (dados já existem!)
  • Acesso a dados ricos e atualizados
  • Foco no seu produto, não na coleta de dados
  • Escalabilidade (a API aguenta o tráfego)

🚀 Passo a Passo: Criar um Site com API

1️⃣ Encontre a API

Busque em github.com/public-apis/public-apis ou Google: "API de [tema]"

2️⃣ Leia a Documentação

Entenda: URL base, endpoints, parâmetros e formato da resposta (JSON)

3️⃣ Teste no Navegador

Cole a URL na barra: pokeapi.co/api/v2/pokemon/pikachu e veja o JSON

4️⃣ Use fetch() no JavaScript

Chame a API com async/await e trate erros com try/catch

5️⃣ Extraia o que Precisa

Navegue o JSON: data.sprites.other['official-artwork'].front_default

6️⃣ Renderize no HTML

Use innerHTML ou createElement para montar a interface

💡 Regra de Ouro: Qualquer dado público que já existe → use uma API. Seus dados privados → crie no seu banco.
