🏗️ Arquitetura Cliente-Servidor

[ CLIENTE (Navegador) ] ─── HTTP Request ───→ [ SERVIDOR (Node.js) ]

│ HTML/CSS/JS GET /api/pokemons │ Express + MySQL

[ CLIENTE ] ←── HTTP Response (JSON) ──── [ SERVIDOR ]

🖥️ Cliente (Front-end)

  • Navegador Web (Chrome, Firefox)
  • HTML5 + CSS3 + JavaScript
  • Envia Requisições HTTP
  • Renderiza a Interface

⚙️ Servidor (Back-end)

  • Node.js + Express
  • Processa Regras de Negócio
  • Acessa Banco MySQL
  • Retorna JSON/HTML

🔄 Protocolo HTTP - Métodos e Status

Métodos HTTP (Verbos)

GET → Buscar dados (Ler)

POST → Criar novo recurso

PUT → Atualizar recurso existente

DELETE → Remover recurso

Códigos de Status

200 OK - Sucesso

201 Created - Recurso criado

400 Bad Request - Erro do cliente

401 Unauthorized - Não autenticado

404 Not Found - Não encontrado

500 Internal Server Error

🅱️ Bootstrap 5 - Grid Responsivo

Sistema de 12 colunas com breakpoints: sm ≥576px | md ≥768px | lg ≥992px | xl ≥1200px

<!-- 1 coluna em mobile, 2 em tablet, 3 em desktop --> <div class="row g-4"> <div class="col-12 col-md-6 col-lg-4"> <div class="card">...Pokémon 1...</div> </div> <div class="col-12 col-md-6 col-lg-4"> <div class="card">...Pokémon 2...</div> </div> <div class="col-12 col-md-6 col-lg-4"> <div class="card">...Pokémon 3...</div> </div> </div>

💡 Mobile-First: As classes sem prefixo (col-12) aplicam em todas as telas. Classes com prefixo (col-md-6) aplicam a partir daquele breakpoint.

⚡ JavaScript Assíncrono - Fetch API

// Consumindo a API REST do nosso servidor async function carregarMeusPokemons() { const resposta = await fetch('/api/meus-pokemons'); const pokemons = await resposta.json(); pokemons.forEach(poke => { // Renderiza cada card dinamicamente no DOM container.innerHTML += ` <div class="card"> <h5>${poke.nome}</h5> <p>Ataque: ${poke.ataque} | HP: ${poke.hp}</p> </div>`; }); }

🔄 O fetch() retorna uma Promise. Com async/await, o código fica legível e sequencial, mantendo a natureza assíncrona.

🔌 Integração com PokeAPI

A aplicação consome dados reais da https://pokeapi.co/api/v2 para descrições, sprites oficiais, stats e cadeia de evolução.

Endpoints Consumidos

GET /pokemon/{name} → Stats, sprites, tipos

GET /pokemon-species/{name} → Descrição (flavor_text)

GET /evolution-chain/{id} → Cadeia de evolução

O que obtemos

🖼️ Official Artwork (sprites HD)

📊 Stats base (HP, Ataque, Defesa...)

📖 Descrição em português (Pokédex)
